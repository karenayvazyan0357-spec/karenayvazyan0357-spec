## Проект

**[Аналитика кликстрима интернет-магазина](https://github.com/karenayvazyan0357-spec/product-analytics-retailrocket)**

Pet-проект на реальных данных Retail Rocket (2,76 млн событий): очистка данных и воронка в PostgreSQL, когорты и ретеншен, проверка гипотез на Python (z-тест, доверительные интервалы), дашборд в Apache Superset и автоматическая сборка Excel-отчёта.

Некоторые результаты: конверсия из просмотра в покупку 0,69%; в выходные конверсия ниже, чем в будни, на 0,24 п.п.; 1% покупателей дают 27% заказов.
